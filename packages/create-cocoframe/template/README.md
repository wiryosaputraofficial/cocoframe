## Commands

- npm run dev — start the development server and watcher.
- npm run check — type-check the application.
- npm run inspect — print routes, islands, components, icons, and contracts.
- npm run generate — generate the typed API client and OpenAPI document.
- npm run build — create the production bundle.
- npm start — run the production bundle.
